How Poemline Works

← Back to Poemline

Poemline turns text into a geometric drawing. Every piece of text — a word, a poem, an entire novel — can be converted into a unique image made of perpendicular strokes on a canvas. Here's exactly how.

Want to see it in action first? Open the interactive toy example — it uses a simplified version of the maths and shows you every step of the conversion as it happens. Drag letters around, change the words, and watch the image transform. Then come back here for the full explanation.

The Big Idea

Imagine a canvas where the bottom-left corner is the point (0, 0) and the top-right corner is (1, 1). Every number between 0 and 1 corresponds to a position along an axis. If we can turn words into numbers between 0 and 1, we can plot them as coordinates and draw a path.

That's exactly what Poemline does — in three steps.

Step 1: The Key — Letters Become Numbers

The Key is an ordered list of symbols (by default, the 52 upper- and lowercase English letters: A, a, B, b, ... Z, z). Each symbol is assigned a value based on its position:

symbol value = position / total number of symbols

With 52 symbols, the first symbol (A) gets 0/52 = 0.0000, and the last (z) gets 51/52 = 0.9808. The values are evenly spread across the range 0 to 1.

Example with 52 symbols:
A = 0.0000,   a = 0.0192,   B = 0.0385,   ...   M = 0.4615,   ...   z = 0.9808

You can reorder, add, or remove symbols from the Key. The values recalculate automatically — the order is what matters, not any fixed assignment.

Try it: In the toy example, drag a letter like t to the very top of the Key and regenerate. The word "the" will suddenly produce a completely different number — and a completely different image. The Key is your cipher.

Step 2: Words Become Fractions — The Weighted Sum

Each piece of text (a word, a sentence, or a line — depending on the separation mode you choose) is converted into a single number between 0 and 1 using a weighted sum:

value = letter₁ × 1  +  letter₂ × (1/N)  +  letter₃ × (1/N)²  +  ...  +  letterₖ × (1/N)ᵏ⁻¹

Where N is the total number of symbols in the Key (e.g. 52).

This works like a positional number system — similar to how decimal digits work, but in base N. The first letter has the most influence on the final value, the second letter refines it, the third refines it further, and so on.

Example — the word "Lorem" (N = 52):
L = 0.4231,   o = 0.5577,   r = 0.6731,   e = 0.1731,   m = 0.4808

value = 0.4231 × 1 + 0.5577 × (1/52) + 0.6731 × (1/52)² + 0.1731 × (1/52)³ + 0.4808 × (1/52)⁴

≈ 0.4341

The result: "Lorem" maps to roughly 0.43 — a point near the middle of the canvas.

The toy example uses a simpler method: it concatenates two-digit numbers instead of using the weighted sum (e.g. "cat" → "06 00 38" → 0.060038). This is easier to follow but produces blockier images. The main Poemline tool uses the weighted sum for smoother, more organic results.

Why this formula?

  • Full range: An infinite string of the first symbol (e.g. "AAAA...") converges to exactly 0. An infinite string of the last symbol (e.g. "zzzz...") converges to exactly 1. Every possible text maps somewhere in between.
  • Uniqueness: No two different texts produce the same number — each text has its own unique point in the 0–1 range.
  • Smooth distribution: Words starting with similar letters land near each other, but subsequent letters spread them apart. This creates organic, flowing patterns rather than blocky grids.

Step 3: Numbers Become a Drawing

The canvas is treated as a graph with coordinates from (0, 0) at the bottom-left to (1, 1) at the top-right. The sequence of numbers is turned into a path of perpendicular strokes:

1
The pen starts at the left edge (x = 0). The first number sets the starting height (y-coordinate).
2
The second number moves the pen horizontally to that x-position — this is the first visible stroke, always starting from the left edge.
3
The third number moves the pen vertically to that y-position.
4
This alternation continues — horizontal, vertical, horizontal, vertical — creating a path of perpendicular strokes across the canvas.

Each stroke corresponds to one piece of text. The result is a unique geometric fingerprint of whatever you typed in.

Try it: In the toy example, type "aaa bbb zzz" and generate. You'll see the strokes reach from the very bottom-left to the top-right of the canvas — the full range in action.

Separation Modes

You choose how the text is split into pieces, and each piece becomes one number (one stroke):

  • Space — every word (separated by whitespace) becomes a stroke. A short poem might produce 30–50 strokes.
  • New line — every line of text becomes a stroke. Fewer, longer strokes.
  • Full stop — every sentence (ending at a period) becomes a stroke. The fewest, boldest strokes.

The same text looks very different depending on the mode — try switching between them on the main tool!

The Key as a Cipher

Reordering the Key changes the value assigned to every letter, which changes every number, which changes the entire drawing. The same text with a different Key order produces a completely different image.

Think of the Key order as a secret — if two people use the same Key, the same text will always produce the same image. Change the Key, and the image changes entirely.

Can You Reverse It?

In theory, yes — if you know the Key order and have infinite precision, you could read the exact coordinates of each stroke and decode them back to the original letters. In practice, screen resolution limits this. A 512px canvas can only distinguish positions about 0.002 apart, which is enough to recover the first letter or two of each word, but not the full text.

Fun fact: To perfectly reverse a 10-letter word with a 52-symbol key, you'd need to measure a position to within 1/52¹⁰ of the canvas width — that's about 0.000000000000000007 of a pixel. You'd need a canvas the size of a galaxy, or strokes thinner than an atom. The maths works; the physics doesn't quite cooperate.

Summary

Poemline is a simple chain: letters → numbers → coordinates → drawing. Every text that has ever been written, or ever will be, has a unique geometric representation waiting to be drawn. The conversion is deterministic, reversible in theory, and produces surprisingly beautiful patterns from ordinary words.
